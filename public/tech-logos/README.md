# Teknoloji logoları

Bu klasördeki SVG dosyaları, [Devicon](https://github.com/devicons/devicon) koleksiyonunun `icons/<ad>/<ad>-original.svg` dosyalarından alınmıştır. Arayüzdeki ikonlar ilgili teknolojilerin özgün marka şekillerini ve renklerini kullanır.

Kullanılan logolar: Android, C#, Firebase, Git, Java, Jetpack Compose, Kotlin ve SQLite. Dosyalar yerel olarak sunulur; sayfa açılırken harici logo servisine istek gönderilmez.
